## 🔧 Technology Stack

### Current Infrastructure
- **Backend:** Node.js 18 + Express.js
- **Bot Framework:** Telegram Bot API
- **OCR:** Tesseract.js (traineddata for 8 languages)
- **Document Processing:** mammoth, pdfjs-dist, xlsx
- **Storage:** Ali OSS (Object Storage Service)
- **Deployment:** Docker + Docker Compose
- **CI/CD:** GitLab CI + Jenkins

### Why This Stack?
- ✅ **Proven Technology:** Battle-tested frameworks
- ✅ **Cost-Effective:** Open-source components
- ✅ **Scalable:** Cloud-native architecture
- ✅ **Maintainable:** Modern development practices
- ✅ **Secure:** Enterprise-grade security
